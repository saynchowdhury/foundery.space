## 2025-05-14 - [Aesthetic Consistency & Feedback]
**Learning:** In technical or "cyberpunk" themed UIs, buttons should have variants that match the high-intensity aesthetic (e.g., uppercase mono-technical fonts) to maintain immersion. Providing immediate feedback via toasts for local state changes (like "Applied" status) compensates for the lack of backend persistence.
**Action:** Always check if a component needs a "technical" variant when placed next to stylized primary actions. Use `sonner` for non-intrusive confirmation of user actions.
