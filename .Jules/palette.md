# Palette's Journal - Foundery.Space

## 2025-05-15 - Initial Setup
**Learning:** Foundery.Space uses a futuristic, technical aesthetic (ASCII headings, monospace fonts, brackets) which must be preserved when adding UX improvements.
**Action:** Always use existing technical design tokens (e.g., `font-mono-technical`, `border-white/5`, `text-brand`) and match component patterns like `[...]` wrappers for icons.
