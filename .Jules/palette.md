## 2025-06-11 - [Accessibility and User Feedback Enhancements]
**Learning:** Accessibility standards for this repository require descriptive ARIA labels for icon-only buttons. The mobile menu and search clear buttons were missing these labels. Additionally, the application uses `sonner` for toast notifications, providing a consistent way to give user feedback on state changes.
**Action:** Always include ARIA labels for icon-only buttons and utilize `sonner` for immediate feedback on interactions like marking an opportunity as applied.
